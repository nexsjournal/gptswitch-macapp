# 页面模板、系统交互与无障碍

## 1. 可复用模板

| 模板 | 组成 | 适用 |
| --- | --- | --- |
| T01 状态概览 | PageHeader + CurrentConfig + StatusPanel + RecentProviders + ApplyBar | 概览 |
| T02 列表详情 | Header + FilterBar + ListPane + DetailPane + 局部保存栏 | 供应商、诊断历史 |
| T03 复杂编辑 | Breadcrumb + 分组表单 + 生效预览 + StickyFooter | 模型能力、连接高级设置 |
| T04 数据表 | Header + Toolbar + SelectionBar + Table + Pagination | 模型目录、日志 |
| T05 变更事务 | TargetSummary + Diff + Impact + Progress + Recovery | 应用、恢复、迁移 |
| T06 设置 | Header + SectionList + 同宽表单块 | 主题、网络、后台行为 |

页面实例只组合这些模板，不为每页发明另一套卡片间距和标题大小。组件分层为基础 token → 基础控件 → 业务组件 → 页面模板 → 页面实例。

## 2. 系统状态矩阵

| 情况 | 页面表现 | 主动作 | 不做 |
| --- | --- | --- | --- |
| 无 Codex | 安装检测空态 | 手动定位/查看安装指引 | 自动改任意 `.codex` |
| 无供应商 | 引导空态 | 添加供应商 | 显示大量不可用品牌卡 |
| 没有 Key | 详情缺项 | 添加 Key | 反复自动探测 |
| 模型列表失败 | 内联错误，保留已有模型 | 手动添加/重试 | 清空模型 |
| 模型目录变更 | 常驻应用栏 | 查看差异 | 隐式重启 |
| 运行请求忙 | 影响说明 | 稍后应用 | 强杀全部 Codex |
| 配置冲突 | 比较页 | 重新计划 | 覆盖新文件 |
| 凭据库锁定 | 明确系统状态 | 解锁后重试 | 明文回退 |
| 网关停止 | 顶部状态条 | 启动服务 | 显示全部 Key 失效 |
| 未支持版本 | 兼容信息卡 | 查看验证范围/原生模式 | 勾选后假装已兼容 |
| 仅部分测试成功 | 阶段结果 | 修复失败项目 | 统一绿色“成功” |

## 3. 表单与保存规则

用户输入以本地草稿保存，非秘密字段可在页间保留；秘密字段不持久化草稿。字段变更点亮“未保存”标记。Esc 关闭浮层，但有未保存内容时显示“继续编辑/放弃更改”；不把“放弃更改”放在默认焦点。

同步格式校验在 blur/提交执行；网络检查仅明确点击触发。错误显示在相关字段下，顶部提供汇总跳转；校验完成后不自动将页面滚回顶部。

设置开关仅用于低风险即时偏好。涉及外部配置、目录发布、Key 调度、重启的操作都经过应用服务，UI 不乐观宣称成功。

## 4. 键盘与焦点

- Tab 顺序符合视觉阅读；固定底栏排在表单之后；无正 tabindex。
- Cmd/Ctrl+K 可做本工具导航/操作搜索，P1 实现；首发不拦截 Codex 快捷键。
- Cmd/Ctrl+S 在表单中保存草稿，不应用/重启；Esc 关闭当前浮层；Enter 不在多行框中误提交。
- Dialog 打开聚焦标题或首输入；关闭返回触发控件；批量删除后聚焦相邻行或新增入口。
- 表格行不全体变成无语义 clickable div；使用按钮/链接和明确选择控件。
- 加载/测试结果用 aria-live polite，错误用 alert；流式日志不每条都打断读屏。
- 焦点环 2 px，offset 2 px，不被 overflow 裁切；高对比模式保留系统边框。

## 5. 缩放与平台规则

200% 缩放时表单与提示不遮挡；主要任务在最小窗口仍可完成。长 URL、模型 ID 可换行/复制；重要差异不得只 hover 可见。UI 支持系统字体大小，禁止用整页 CSS scale 假缩放。

macOS 标题栏拖拽区与交通灯不重叠可操作控件；Windows 支持窗口最大化和常见吸附，不复制 macOS 红黄绿按钮。两个平台信息架构一致，窗口 chrome 尊重平台习惯。

## 6. 交互性能

保存/点击反馈目标 100 ms 内呈现；网络仍在执行时只更新必要局部。1000 条模型目录采用分页/虚拟化并保持键盘可访问性，搜索 debounce 建议 150 ms，响应后保留选中项。不要为所有结果同时创建 Tooltip/Popover 重型实例。

自动刷新不得抢走焦点、重排正在操作行或滚回列表顶部。状态过期是单独标签，不把老结果直接抹掉导致闪烁。

## 7. 设计验收清单

设计交付需附每页 default / empty / loading / error / partial / dirty / applied 状态；所有核心步骤有键盘路径；图标、文字、颜色有统一 token；数值与字段来源可查；待应用清单能说明重启理由。

这轮交付是文字规格和线框，不包含已运行原型。实现阶段应以 1280×840、960×640 和 200% 缩放三组截图做视觉检查，分别在 macOS 和 Windows 上验收。
